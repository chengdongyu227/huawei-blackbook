# 华为笑话档案馆 / Huawei Blackbook

[中文](#中文) | [English](#english)

---

## 中文

本项目旨在收集、整理和存档所有与华为公司及其相关品牌有关的公开笑话、争议事件、网络名场面与互联网记忆，防止一些故事随着时间推移被悄悄改写。

### 投稿方式

欢迎通过 Issue 或 Pull Request 投稿。建议每条记录尽量包含：

1. 事件名称与发生日期
2. 事件经过及背景
3. 截图、视频或原始链接
4. 新闻报道、官方回应等资料
5. 网页存档链接
6. 后续进展或口径变化

投稿内容应当明确区分：

- 可以核实的事实
- 当事方的指控或回应
- 尚未证实的网络传闻
- 网络段子与讽刺内容
- 投稿者的个人观点

### 项目原则

- 不编造，不断章取义
- 优先保存原始资料
- 对未经证实的内容明确标注
- 尽可能记录完整时间线
- 欢迎补充来源与公开勘误
- 不因立场不同而删除可验证的事实

所有内容仅用于公共事件记录、评论、研究与讽刺，不代表本项目认可任何未经证实的指控。

> 互联网是有记忆的——如果没有，那就帮它建一个。

### 参与贡献

如果你见过值得记录的华为笑话或争议事件，请提交 Issue；如果你已经整理好了材料，欢迎直接发起 Pull Request。

请尽量做到有图有真相、有链接可追溯、有时间线可核查。

## English

This project collects, organizes, and archives publicly available jokes, controversies, notable internet moments, and online memories involving Huawei and its associated brands.

Its purpose is to preserve verifiable records before stories, statements, and public narratives are quietly rewritten over time.

### How to Contribute

Contributions are welcome through Issues and Pull Requests. Each submission should preferably include:

1. The name and date of the incident
2. A summary and relevant background
3. Screenshots, videos, or original links
4. News coverage or official responses
5. Archived copies of relevant web pages
6. Follow-up developments or changes in public statements

Submissions should clearly distinguish between:

- Verifiable facts
- Allegations and responses from involved parties
- Unverified online claims
- Jokes, memes, and satire
- The contributor’s personal opinions

### Project Principles

- Do not fabricate information or quote material out of context
- Preserve original sources whenever possible
- Clearly label unverified claims
- Document complete timelines whenever possible
- Welcome corrections and additional sources
- Do not remove verifiable facts merely because of differing viewpoints

This project is intended solely for documenting, commenting on, researching, and satirizing matters of public interest.

The inclusion of a claim does not mean that this project considers the claim proven.

> The internet never forgets. If it does, we will build a memory for it.

### Contributing

If you know of a Huawei-related joke or controversy worth preserving, please open an Issue. If you have already organized the relevant material, feel free to submit a Pull Request.

Whenever possible, provide images, traceable links, archived sources, and a verifiable timeline.
